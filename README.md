# Sistem Informasi Pendataan Kayu - PT. Margi Jati Makmur 

Repository ini berisi *source code* untuk aplikasi web inventori kayu, mencakup manajemen bahan baku (log), proses sawmill, dry kiln, hingga transaksi penjualan.

## Tech Stack
* **Frontend:** NextJS, Tailwind CSS, TypeScript
* **Backend:** NestJS, TypeScript
* **Database:** PostgreSQL

## Struktur Direktori
* `/frontend` - Berisi source code antarmuka pengguna (Next.js).
* `/backend` - Berisi source code logika server dan API (NestJS).
